### 本轮（#13 / #14）具体做了什么

- **调研纠错**：此前「纯 HTTP / SSR 已走不通」的结论下早了。`www.douyin.com/aweme/v1/web/aweme/detail/` 确实在 Argus 网关后（缺 `a_bogus` / `uifid` 一律 403），但 `short_videos` 用的移动端老接口 `api.amemv.com/aweme/v1/aweme/detail/` **不在网关后，免 Cookie / 免签名**。实测真实 ID `7685345542323834441`：HTTP 200、`status_code:0`、`aweme_detail.video.play_addr.url_list` 3 条无水印直链且已带 `mime_type=video_mp4`，`desc` / `author.nickname` 齐全。
- **`douyin.rs`（新增，独立实现、不复制 MIT 项目代码）**：`is_douyin_page()` 按主机名判定并排除 CDN 直链；`extract_aweme_id()` 覆盖 `/video/<id>`、`/share/video/<id>`、`/note/<id>`、`modal_id`；短链先跟随 302；`parse_detail()` 校验 `status_code` / `aweme_id` 一致性，取 `play_addr.url_list` 中 `https://` 且不含 `playwm` 的正片，缺失回退 `bit_rate_list`；识别 `filter_reason=core_dep`、图集 / 实况；`ensure_mime_type()` 用字符串拼接补 `mime_type=video_mp4`（不重序列化 query，避免改坏签名编码）；`suggested_filename()` 生成「标题 - 作者.mp4」并清洗 `#话题` 与 Windows 非法字符。**9 个纯函数单测**。
- **`Engine::add`（`manager.rs`）**：在 `media_page_blocker` 拦截快手 / 聚合页**之后**，对 `TaskKind::Media` + 抖音作品页调用 `douyin::resolve()`；成功后转 `TaskKind::Http`、替换 URL 为直链，设置 `Referer: https://www.douyin.com/`、`DOWNLOAD_UA`、中文建议名、`prefer_header_filename=false`，复用 A 档引擎（分片、SHA-256 回读、慢连接换线、限速、断点续传）。解析失败直接给可操作指引，不创建必然失败的任务。
- **B 档整体删除**：`EngineOptions` 的 `media_cookie_browser` / `media_cookie_file`、`media.rs::cookie_args()` / `apply_cookie_args()` 及两条 yt-dlp 命令透传、前端 `types.ts` / `store.ts` 字段与设置页两个控件、`functional_036.rs` 旧断言、`background.js` 8 处 Cookie 引导文案。`failure_hint()` 改为不引导配置任何凭证。
- **契约重写**：`check_media_parse_contract.cjs` 从「B 档 Cookie 通道」改为 6 组断言 —— 移动端接口 / `Media→Http` 转换（含顺序与三件套）/ B 档源码级删除 / 扩展跨层判定与文案 / 凭证边界 / 版本纪律。**不再「假通过」**（旧契约 PASS 只代表代码形状，不代表功能可用）。
- **验证**：`cargo test -p fluxdl-engine` 140 项全绿；`npm run build`（`tsc --noEmit` + vite）通过；`node --check browser-extension/*.js` 全 OK；6 个契约全 PASS；真实接口连通性实测通过。

## 七、已知风险 / 坑

1. **PC Web 接口走不通，移动端接口可用（结论已修正）**：`www.douyin.com/aweme/v1/web/aweme/detail/` 在 Argus 网关后，缺 `a_bogus` / `uifid` / `x-secsdk-web-signature` 一律 403，随包 yt-dlp 不生成签名、Cookie 不够，`iesdouyin` 分享页只剩反爬壳。但**移动端 `api.amemv.com/aweme/v1/aweme/detail/` 免 Cookie / 免签名实测可用** —— 不要再说「纯 HTTP 全部走不通」。
2. **非官方接口随时可能变**：`api.amemv.com` 是站点未公开接口而非官方 API；部分作品返回 `filter_reason=core_dep`（删除 / 私密 / 风控），个别 `play_addr` 落在 `.mp3` 或图集 / 实况，需错误处理。契约已按真实链路断言，旧版「B 档契约假通过」问题已消除。
3. **CDN 防盗链与直链时效**：抖音直链必须带 `Referer: https://www.douyin.com/`（由 `Engine::add` 设置），缺了 403；直链带时效签名，解析后应尽快下载，别长期缓存。
4. **抖快直链无扩展名**：任何新增下载入口都必须显式 `kind:"http"`，否则会被 `looks_like_media()` 误判成 Media 任务再被拦，表现为「点了没反应」。
5. **workspace 结构陷阱**：根 workspace 只含 engine，Tauri app 是独立 workspace；在根目录重编只会更新 engine，`fluxdl.exe` 仍是旧件（本轮实测 SHA 完全没变）。必须在 `src-tauri/` 内编译，并用 `strings` 抽查内嵌版本号。
6. **交付包两层是独立拷贝**：`/workspace/fluxdl-dist/` 顶层与 `archive-0.3.9/` inode 不同，改一处必须同步另一处；源码包 zip 内也含文档副本，靠 `sync_src_zip_039.py` 同步。
7. **真机已验证通过（2026-11-09）**：抖音免 Cookie 解析链路经用户 Windows 真机实测能正常下载，可下「已修复」结论。仍保留两点提醒：`api.amemv.com` 是未公开接口、随时可能变（见第 2 条）；覆盖范围是抖音单视频作品页 / 短链，图集 / 实况 / 风控作品与快手整页链接不在其内。
8. **主仓库位置**：`/workspace` 顶层只有 `fluxdl-dist` 和 `README.md`，**不是** git 仓库；源码在 `/root/work/winbuild/fluxdl`。
9. **推送 GitHub 走数据接口，别用 `git push`**：本环境 `github.com:443` 的 git smart-HTTP（`git push` / `ls-remote`）卡在 TCP `Trying …:443`，超时 2 分钟无果；但 `api.github.com` 与 `github.com/.../info/refs` 的 HTTP GET 都正常（1s 内 200）。可行做法是用 GitHub Git Data API 手动建提交：`POST /git/blobs`（base64）→ `POST /git/trees`（`base_tree` = 父 tree）→ `POST /git/commits`（author/committer 沿用本地 `FluxDL Baseline <baseline@local>` + 原时间戳 `+0800`，message 取 `git cat-file -p HEAD` 首个空行之后）→ `PATCH /git/refs/heads/dev/0.3.9`（**复数 `refs`**，单数 `ref` 会 404；`force:false` 保证 fast-forward）。逐字节复现可让远端 commit hash 与本地**完全一致**。token 只放 `/tmp` 临时文件、用完删，不写仓库 / `.git/config`；因明文出现在对话中，建议用后轮换。
10. **快手不能照搬抖音方案**：`short_videos` 里快手走 `window.INIT_STATE` / `APOLLO_STATE` / `mainMvUrls` / `VisionVideoDetailPhoto` 且带 Cookie；随包 yt-dlp 无 Kuaishou 提取器，故快手仍拦截整页解析、只走「本页资源」直链。
11. **`main` 与 `dev/0.3.9` 是分叉的两条独立历史**：远程 `main` 原为 0.3.6（26 个提交），`dev/0.3.9` 是旧 B 档代码线（在 `249cc51` 后另有 2 个「feat: update workspace」提交，含一个扩展 zip 和一个 `primary` 去重修复），与本地 0.3.9 免 Cookie 新版无共同祖先。发版采用「本地 HEAD 完整 tree → parent=`c2fd76c` 的发布提交」，**没有 force、没有覆盖 `dev/0.3.9`**。后续若在 `dev/0.3.9` 上继续开发，注意它仍是旧 B 档代码、缺 `douyin.rs`。
