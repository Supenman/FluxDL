# FluxDL v0.4.3 发布说明（草稿）

> 适用平台：Windows 10/11 x64 · 浏览器扩展：v2.2.2

## 亮点总览

`v0.4.3` 是一次覆盖 **下载引擎底层、IDM 经典桌面交互与模型/压缩包高效工作流** 的大版本更新，全链路保持零新增重型外部依赖与零凭证安全边界。

### 一、下载引擎与可靠性
- **NTFS 稀疏 `.part` 文件预分配**：≥5 MB 大文件在 Windows NTFS 上开启稀疏写入，避免多线程起速时同步填零导致的磁盘卡顿，落盘前自动恢复常规属性。
- **下载前磁盘空间预检**：按「剩余未写字节 + 32 MB 安全余量」核对目标分区空间，避免下到末尾才因磁盘满报错。
- **多 IP 竞速优选 DNS（`dns.rs`）**：对多 IP CDN 域名（ModelScope / HuggingFace / GitHub Releases 等）并发 TCP 竞速优选最快节点并缓存 5 分钟；慢连接换线、超时或 5xx 时自动失效旧节点重新竞速，支持 443 全拒时快速回退 80 端口。
- **过期链接续期**：403/410 签名直链过期时可在详情抽屉一键替换新链接，复用重叠字节校验安全保留 `.fluxdl-part` 进度。
- **用户 SHA-256 校验和核对**：支持粘贴官方 64 位 SHA-256；未完成任务在落盘前自动校验，已完成任务流式即时核对。
- **大文件「校验中…」状态提示**：几十 GB 大模型写完做磁盘回读校验时明确展示「校验中…」，不再停在 `100% 下载中` 造成卡死错觉。
- **关键缺陷修复**：
  - 修复动态分段再平衡时原连接未感知边界收缩导致的重叠下载与字节计数膨胀（如 `42.6 GB / 25.3 GB`）。
  - 修复失败任务退出未条件清空 `cancel` 槽位导致点重试/继续永久卡死在「已暂停」的问题。
  - 修复无强 ETag 链接断线后全量重下的问题，改为重叠字节校验恢复。
  - 补全 `Content-Disposition: filename=` 百分号编码中文文件名自动解码。

### 二、IDM 经典全宽桌面界面与高频交互
- **全宽通栏经典布局**：顶部 24px 菜单栏（任务 / 文件 / 下载 / 视图 / 帮助）+ 58px 全宽大图标工具栏 + 左侧 178px 折叠分类树（全部下载 / 未完成 / 已完成 / 队列）+ 右侧满屏 27px 高密度细网格表。
- **列表多选与底部浮动批量条**：支持 `Ctrl` / `Shift` 多选与 `Ctrl+A` 全选，浮出底部批量条一键暂停、继续、移入队列或移出列表。
- **底栏快捷胶囊与挂机动作**：状态栏直接切换全局限速、通知临时免打扰（30 分钟 / 1 小时 / 8 小时 / 本次运行）以及「全部完成后自动退出 / 睡眠 / 关机」（带 30 秒可取消倒计时）。
- **系统级体验**：接入 Windows 任务栏图标总进度条；批量完成通知 2.2 秒窗口自动汇总；新增桌面置顶拖拽悬浮球（菜单「视图 → 显示/隐藏桌面拖拽悬浮球」）。
- **高频渲染性能优化**：为 `TaskRow` 增加 `React.memo` 精准比较，收紧抽屉与进度窗状态订阅，移除遮挡视线的悬浮预览卡片。
- **设置页分组标签导航 & 按站点规则**：设置页顶部按功能分组切换；新增按域名预设连接数、限速、Referer 与 User-Agent 的站点规则。

### 三、模型仓库、网页抓链与 ZIP 增强
- **HuggingFace / ModelScope / GitHub Release 一键解析**：粘贴仓库或 Release 链接即可拉取全部文件与体积，勾选后一键批量入队并自动挂载官方 `SHA-256` 校验和。
- **网页批量抓链器（Link Grabber）**：抓取任意目录索引页或下载页链接，自动优先勾选常见可下载文件。
- **ZIP 自动解压 & 远程 ZIP 在线挑单文件**：支持 `.zip` 下载完成后安全自动解压（严格防 Zip-Slip 路径穿越）与手动一键解压；新建弹窗贴入 `.zip` 直链可直接在线查看压缩包目录，仅提取所需单个文件。

### 四、浏览器扩展自动接管修复
- 修复 Chrome/Edge 重启或重载扩展时回放历史下载记录导致自动重下旧任务的问题（严格校验 `in_progress`、30 秒 `startTime` 窗口、跳过其他扩展下载与 `storage.session` 跨休眠去重）。
- 桌面端 `/api/downloads` 增加同 URL 幂等去重；手动新建任务不再强制二次审核，浏览器自动接管审核改为设置页可选开关（默认关闭）。
