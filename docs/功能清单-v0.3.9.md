## 三、⚠️ 有条件可用 / 已知限制

| 项 | 说明 |
|---|---|
| **B 站等 yt-dlp 通道速度较慢** | 匿名 CDN 常对单条连接限速到几百 KB/s；`--concurrent-fragments` 4→8 实测无效。经 0.3.6→0.3.9 逐版本比对，代码与随包 `yt-dlp.exe` 完全一致，属**站点侧策略变化**而非版本回归。详见 `docs/B站下载慢-根因定位与修复建议.md` |
| 抖音 `api.amemv.com` 非官方接口 | 站点未公开接口，随时可能变更；部分作品返回 `filter_reason=core_dep`；直链带时效签名与 `Referer` 防盗链，解析后尽快下载 |
| 需登录才能观看的站点内容 | YouTube 等仍在站点名单内，但零凭证策略下不携带登录态，遇风控 / 需登录视频会解析失败；改用「本页资源」直链 |
| 扩展「解析正片」 | 真机未稳定出现该条目（多数新版页面不把详情渲染在明文 JSON / 内联脚本里）。**抖音主路径是桌面端免 Cookie 解析，不依赖它** |
| 不承诺 | 不承诺不限速、不承诺 100% 解析成功；失败时请用「本页资源」直链 |
| 平台 | 官方仅发布 Windows x64 成品；Linux 仅源码构建参考，不发成品包 |

## 四、❌ 明确不支持

| 项 | 原因 |
|---|---|
| 读取 / 携带 / 落盘任何浏览器 Cookie、登录态、token | v0.3.0 起的隐私红线；旧的「yt-dlp + 本机浏览器 Cookie」方案真机证伪后整体删除，设置页无 Cookie 配置项 |
| 快手网页链接整页解析 | 随包 yt-dlp 没有 Kuaishou / Kwai 提取器，建任务时拦截并给指引 |
| 抖音图集、实况 Live Photo、已删除 / 私密 / 被风控作品 | 解析会给可操作提示，改用「本页资源」直链 |
| 抖音主页批量、站点首页 / 发现 / 精选 / 推荐等无 id 聚合页 | 建任务时拦截 |
| 抖音原画 `quality=original`、多档码率优选、图集原图、背景音乐 / 封面 / 时长等元数据 | 未实现（参考项目 `short_videos` 的部分能力未引入） |
| 小红书 / 微博 / 头条 / 皮皮虾 / 网易云等站点的**结构化整页解析** | 未引入；部分站点可经 yt-dlp 通用提取器尝试，不承诺成功 |
| Linux 成品包 | 已停发，源码仍可自行构建 |

## 五、能力边界速查（按站点 / 链接类型）

| 链接类型 | 整页解析 | 推荐方式 | 实际通道 |
|---|---|---|---|
| 普通文件直链 `.zip/.exe/.mp4` | — | 粘进「新建任务」 | A 档 aria2 多连接 ✅ |
| CDN 视频直链（含无扩展名 `.../play/?mime_type=video_mp4`） | — | 「本页资源」点下载 / 粘贴新建任务 | A 档 aria2 多连接 ✅ |
| 抖音单视频详情页、短链、带 `modal_id` 精选页 | ✅ | 复制链接 → 桌面端「新建任务」 | 免 Cookie 解析 → A 档 ✅ |
| 抖音图集 / 实况 / 风控作品 | ❌ | 「本页资源」直链 | A 档（若能嗅探到） |
| 抖音 / 其它站点首页、发现、精选、推荐（无 id） | ❌ | 打开具体视频再试，或用「本页资源」 | — |
| 快手网页链接 | ❌ | 「本页资源」里选视频直链 | A 档 |
| B 站视频页 | ✅ | 页面点「解析并下载本页视频」 | yt-dlp 原生（⚠️ 单连接可能慢） |
| 微博 / 小红书 / 爱奇艺 / 优酷 / 腾讯视频 / 知乎 / 西瓜 / A 站 / 网易云音乐 / YouTube / Vimeo / TikTok / X / Instagram / Facebook / Twitch / Dailymotion / niconico 等名单内站点 | ✅ 尝试 | 页面解析或粘贴链接 | yt-dlp 原生（零凭证，需登录内容可能失败） |

> 站点名单共 27 个主机名，前端 `src/lib/format.ts::MEDIA_HOSTS` 与 `src-tauri/src/lib.rs` 的 `looks_like_media` 逐项一致，由契约脚本锁定。

## 六、按场景该怎么用

| 场景 | 操作 | 结果 |
|---|---|---|
| 下载一个普通文件 | 复制直链 → 桌面端「新建任务」粘贴 | 多连接下载 |
| 下载抖音单个视频 | 复制详情页 / 短链 → 桌面端「新建任务」粘贴 | 自动免 Cookie 解析为无水印直链后下载 |
| 下载 B 站视频 | 在页面点「解析并下载本页视频」 | yt-dlp 解析并合并 mp4（可能较慢） |
| 快手 / 聚合页 / 解析失败 | 打开浏览器扩展弹窗 → 「本页资源」→ 选视频直链 → 下载 | 普通下载 |
| 「本页资源」为空 | 说明该页面只提供分片流、未渲染明文直链 | 换来源，或改用抖音详情链接走桌面端解析 |
| 升级扩展后功能异常 | `chrome://extensions` 重新「加载已解压的扩展程序」并刷新目标页 | 探针在 `document_start` 注入，页面先开则需刷新 |

## 七、项目红线（设计约束，非缺陷）

1. **零凭证**：不读取、不传输、不落盘任何浏览器 Cookie / 登录态 / token。
2. **不逆向、不计算反爬签名**，不内嵌浏览器内核。
3. **不复制 AGPL 代码**；参考 `jiuhunwl/short_videos`（MIT）仅确认抖音移动端详情接口字段形态，`douyin.rs` 为独立实现。
4. **不制造必然失败的任务**：快手整页、无 id 聚合页、解析失败的抖音在建任务时拦截并给可操作指引。
5. **不夸大能力**：能力边界、非官方接口风险、B 站限速如实写明。
