下载 FluxDL 0.3.0

扩展 v2.1 + 内置 yt-dlp / ffmpeg。仅提供 Windows 版本。不用装 Rust / Node，不用编译，也不用自己装下载工具。

装过旧扩展的一定要重新加载一次：本版扩展新增了 cookies 权限，Chrome 不会自动给旧扩展升级权限。请在 chrome://extensions 里点 FluxDL 扩展的重新加载（或移除后重新「加载已解压的扩展程序」），否则 YouTube 登录状态带不过去。
这一版改了什么
  • 装一次，以后点一下就能更新：设置页新增「主程序版本」。更新只下载约 10 MB 的 fluxdl.exe 存进版本库，校验通过后自动完成替换，窗口先关、1~2 秒后自己重开——不重下 47 MB 安装包、不重装、不需要管理员权限。
  • 三道回滚：升级包 SHA-256 不符当场删除；替换中途失败用 .bak 还原；新版本连续两次启动不起来，自动回退到上一版本。也可以手动在「主程序版本」里一键退回去。
  • 视频下载提速且不再空转：分片并发 4 路，B 站自动切 tv/app 客户端绕开单连接限速；失败立即报错，不再「下载中 0B/未知」。
  • 不再读取任何 cookie：登录凭证不离开浏览器，磁盘上也不会留下凭证文件；媒体任务只保留国内站点。
  • yt-dlp / ffmpeg 可选版本：设置里能装多个版本、随时切换、一键回滚。YouTube 改版导致新版解析失败时，回滚旧版往往立刻恢复下载。
  • 修掉 YouTube「Sign in to confirm you're not a bot」：扩展自动把浏览器里 YouTube / Google 的登录 cookie 转成 cookies.txt 交给 yt-dlp，用完即删，不用手动导出，也不用装 Node。弹窗里可关闭。
  • 视频「没有可用清晰度」时自动重试：遇到 Requested format is not available，自动换一组不依赖 PO Token 的 yt-dlp 客户端并放宽清晰度再试一次；仍失败会给出中文排查指引。
  • yt-dlp 自动更新（修你刚报的「页面需重载」）：随包内置的 yt-dlp 会在后台静默升级到新版（YouTube 频繁改版，旧版必崩）；遇到 The page needs to be reloaded 这类报错，会强制更新 yt-dlp 后自动重试。设置页可关闭自动更新。
  • 修掉 Windows 中文系统 yt-dlp 崩溃：Errno 22 / Exception ignored while flushing sys.stdout，改为 UTF-8 输出 + 字节级读取。
  • 不再有「接管范围」设置：所有 http(s) 下载一律交给 FluxDL，小文件、图片、PDF 都不跳过。
  • 像 IDM 一样嗅探页面资源：点扩展图标就能看到本页的音视频与文件，可单条或全部发送；B 站 / YouTube 用「解析并下载本页视频」交给内置 yt-dlp。
  • 删除了旧版「用 FluxDL 下载当前页面」右键菜单；yt-dlp 与 ffmpeg 已随包附带。

下载之后怎么测

  1. 装好（或解压后）启动 FluxDL。
  2. Chrome 打开 chrome://extensions → 开发者模式 → 加载包里的 browser-extension 文件夹；旧版必须点重新加载。
  3. 随便点一个网页下载链接：浏览器下载被自动接管、FluxDL 窗口冒出任务并开始下载 = 通过。
  4. 先在 Chrome 登录 YouTube，再打开视频页点扩展里的「解析并下载本页视频」。弹窗里的「视频站点自动带上登录状态」保持开启。
